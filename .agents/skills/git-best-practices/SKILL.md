# git-best-practices

## When to Activate

Keep commits atomic, descriptive, and cleanly scoped without committing secrets or build artifacts.

## Guidelines

- Follow `AGENTS.md` and the page-based frontend architecture.
- Verify changes with `npm run typecheck`, `npm run lint`, and `npm run test`.
