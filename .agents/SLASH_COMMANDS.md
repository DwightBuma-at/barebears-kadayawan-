# Antigravity Slash Commands Quick Reference

- `/visual-qa` — Run visual QA, responsive overflow checks, and WCAG 2.2 AA verification across viewports.
- `/implement-design` — Translate a design brief or reference screenshot into production React + Tailwind code.
- `/ui-cleanup` — Audit and refine spacing, alignment, typography, and component consistency.
- `/prompt-to-plan` — Break a feature request into a structured 10-step implementation plan before coding.
